Little Lemon API

This page is served by Django as static HTML. The API endpoints are:

  • /auth/users/ — register a user (POST)
  • /restaurant/api-token-auth/ — get a token (POST)
  • /restaurant/menu/ — menu items (GET, POST)
  • /restaurant/menu/<id> — one menu item (GET, PUT, PATCH, DELETE)
  • /restaurant/booking/tables/ — table bookings (GET, POST, PUT, PATCH, DELETE)
